# Advanced stage entrypoints

These scripts expose individual HarnessLens stages for debugging, artifact
reconstruction, and controlled experiments. Most users should run the complete
workflow through `../../run_e2e.py` or `../run_e2e.sh` instead.

Run `python scripts/stages/<script>.py --help` from the repository root after
`scripts/setup.sh` has installed HarnessLens in editable mode.
